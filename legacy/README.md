# Legacy notebooks (original submission, June 2026)

These notebooks produced the results of the original PeerJ submission. They use single
train/validation splits (`validation_split=0.2`), pixel-space SMOTE, augmentation and
fine-tuning, and they do not implement the leakage-safe protocol of the revised manuscript.

They are kept for transparency only. No table, figure or number in the revised manuscript
comes from this folder. See the main README for the code that does.

## results/
Result files and figures produced by the original-submission notebooks. They used image-level splits that allowed source-image leakage and are superseded by outputs/results/. Retained for transparency only.
